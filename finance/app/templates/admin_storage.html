Database

A full, consistent snapshot of the entire SQLite database — every user's accounts, transactions, statements and rules — for a manual backup or to open with an external SQLite tool. Generated fresh on each click; nothing is kept on the server after the download finishes.

Download database (.db)

Import database

Restores a previously-downloaded .db backup — mainly for after reinstalling this app (a fresh install has no data of its own until you import one). This replaces every user's entire database at once and can't be undone — there is no per-account or partial import, and whatever is currently stored is gone the moment this finishes. Restart the app right after importing so every background worker picks up the new data instead of whatever it already had open.
