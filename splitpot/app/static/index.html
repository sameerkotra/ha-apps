    How phones link

    📱 Phone notifications (switched on in App settings) go to the phones Home Assistant links to each person: Settings → People → (the person) → Track device, with the Home Assistant Companion app. Add an extra notify service below only for something else (a speaker, a second service). Each person can still turn notifications off under My settings.
