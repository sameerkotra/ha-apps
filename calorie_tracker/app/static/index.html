More about users

There's no way to add a user by hand — a person appears here the first time they open the app. Use the dropdown at the top to switch which person's data you're viewing or editing. Disabling a user just hides them from that dropdown for everyone else; it doesn't lock them out of their own data or delete anything.

Database Backup

Restore from Backup

⚠️ Restoring replaces every household member's data with the contents of the file you upload. There is no merge and no undo — use this only to recover onto a fresh install (e.g. after a reinstall or a lost /data volume), not as routine use.
