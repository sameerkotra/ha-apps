🏠 Home Assistant

Publish daily calories to Home Assistant

Publishes only each person's calories logged today, as sensor.calorie_tracker_<user>_daily_calories — never macros, weight or food names. Turning it on publishes everyone's sensor right away; turning it off removes those sensors from Home Assistant.

Changes apply right away — no restart needed. Only who counts as an admin is set in the app's Configuration tab (admin_users).

Household Users

Everyone listed here has opened this app through their own Home Assistant login at least once — there's no way to add a user manually. Use the dropdown at the top to switch which person's data you're viewing or editing. Disabling a user just hides them from that dropdown for everyone else; it doesn't lock them out of their own data or delete anything.

Database Backup

Download a full, consistent snapshot of the app's SQLite database — every household member's data, not just yours — for a manual backup or to inspect with an external SQLite tool.

⬇️ Download database (.db)

Restore from Backup

⚠️ Restoring replaces every household member's data with the contents of the file you upload. There is no merge and no undo — use this only to recover onto a fresh install (e.g. after a reinstall or a lost /data volume), not as routine use.
